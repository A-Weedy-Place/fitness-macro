# Food data and recipe provenance

Weed Fitness is standalone and uses no paid food/search subscription.

1. Personal cookbook first: saved nutrition is authoritative. A model estimate never silently replaces it. Editing reusable foods changes future logs, not snapshot calories in old entries.
2. Manual local search: bundled estimated foods plus saved foods/recipes, regional aliases and related-word matching work offline. Online search/barcodes use Open Food Facts; local search never requires the AI provider. The removed PC USDA index is not an active source.
3. New dishes: the model proposes ingredients/quantities and batch servings. An optional free Wikibooks reference lookup enriches genuinely new dishes, with no more than two total reasoning calls including correction/refinement. Search sends dish names only, not diary/profile/chat. Failed lookup/refinement leaves a labelled estimate, not a fabricated source.
4. Attribution: a matched reference records source title, revision URL and CC-BY-SA4.0 license and shows them in recipe details. It supports ingredient provenance, not verified nutrition. Model-generated URLs are not accepted as evidence. Serving macros are calculated from ingredients and vary with household oil, cooked water and serving size.

Users review actual executable quantities/dates before applying. Manual food and recipe editors remain available. Package nutrition labels beat generic estimates for that exact brand. Regional catalog coverage is incomplete; empty searches and reference misses remain possible, with custom food/recipe creation as the explicit fallback.

## Future dataset expansion

IFCT/USDA ingredient normalization remains a potential expansion, not implemented access. Review redistribution licenses and serving conversions before importing datasets. Do not copy proprietary MacroFactor assets/recipes or claim an AI-approved tag makes a macro estimate factual.
