# Fitness Macro mobile app

Expo SDK 57 / React Native 0.86 local-first nutrition journal.

## Product areas

- `Today`: targets, macro split, meal diary, weight, and activity.
- `Plans`: save a logged day as a reusable menu and apply it to another date.
- `Trends`: calorie adherence, protein hit rate, logging streak, activity, macro split, weight trend, and meal distribution.
- `Food`: local/remote search, barcode number lookup, voice phrase preview, reusable library, and packet-label foods.
- `You`: profile, BMR/TDEE preview, targets, synchronization, and integration status.

See `../docs/testing-guide.md` for setup and the first test sequence.
